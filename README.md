# DeepCode

> Сверхбыстрый TUI-редактор кода с упором на клавиатуру и встроенным headless REST API.

## 🚀 О проекте

DeepCode — это современный редактор кода с текстовым интерфейсом (TUI), написанный на Python (Textual). Включает встроенный локальный HTTP JSON API для управления воркспейсом через curl.

## ✨ Особенности

- Управление с клавиатуры (хоткеи VS Code) и поддержка мыши.
- Встроенный headless REST API (порт 8765) с токенами авторизации.
- Стильный интерфейс в цветовой палитре TokyoNight.
- Автоопределение языка и подсветка синтаксиса (Python, JS, JSON, Bash и др.).

## 🛠 Установка

```bash
pip install -r requirements.txt
python main.py /path/to/project
```
